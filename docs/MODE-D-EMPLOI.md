## 1. Ce qu'est MyCashBill

MyCashBill vous permet de **créer des documents commerciaux professionnels** depuis votre téléphone ou votre ordinateur : tickets de caisse, reçus, devis, factures, bons de commande, bordereaux de livraison…

Avec MyCashBill, vous pouvez :

- créer un document en quelques minutes ;
- l'envoyer à votre client par **WhatsApp**, par **email** ou en le **téléchargeant en PDF** ;
- garder un **historique** de tous vos documents ;
- tenir une **liste de clients** pour ne pas ressaisir leurs coordonnées ;
- programmer des documents qui se créent **automatiquement** à intervalle régulier.

> **Bon à savoir :** l'application est pensée pour un usage au téléphone. Tout ce qui est décrit ici fonctionne aussi sur ordinateur, avec un menu latéral à la place de la barre du bas.

Vous pouvez commencer **gratuitement**. Certaines fonctions sont réservées à l'offre **Pro**, que nous présentons au chapitre 12.

## 2. Créer votre compte

### Étape 1 : ouvrir la page d'inscription

Ouvrez MyCashBill dans votre navigateur, puis appuyez sur **Connexion**, et ensuite sur **Créer un compte**.

### Étape 2 : renseigner vos identifiants

| Champ | Ce qu'il faut écrire |
|---|---|
| **Numéro de téléphone** | Votre numéro de téléphone. Il servira à vous connecter. |
| **Code PIN (6 chiffres)** | Six chiffres de votre choix. Ils seront demandés à chaque connexion. |
| **Confirmer le PIN** | Les mêmes six chiffres, une seconde fois. |

> **Conseil :** choisissez un PIN facile à retenir pour vous, mais difficile à deviner pour les autres. Évitez `123456` ou votre année de naissance.

### Étape 3 : indiquer vos informations professionnelles

| Champ | Ce qu'il faut écrire |
|---|---|
| **Nom du responsable** | Votre nom et prénom. |
| **Nom de l'entreprise** | Le nom sous lequel vous travaillez. |
| **Ville** | La ville où vous exercez. |
| **Mode d'utilisation** | Choisissez **E-commerce** si vous vendez des produits, ou **Prestation** si vous fournissez des services ou de l'artisanat. Vous pourrez le changer plus tard. |
| **Code de parrainage** | Facultatif. Si un ami vous a donné son code, saisissez-le : vous gagnez des jours Pro. |

### Étape 4 : accepter les conditions

Cochez la case **« J'ai lu et j'accepte les Conditions Générales d'Utilisation »**, puis appuyez sur **Créer mon compte**.

### Ce qui se passe ensuite

Votre compte est créé et vous êtes connecté automatiquement. Vous bénéficiez d'un **essai Pro de 5 jours** : pendant ces cinq jours, vous pouvez tester toutes les fonctions Pro.

> **Important :** notez votre numéro et votre PIN dans un endroit sûr.

## 3. Se connecter, et que faire si vous oubliez votre PIN

### Se connecter

1. Ouvrez MyCashBill et appuyez sur **Connexion**.
2. Saisissez votre **numéro de téléphone**.
3. Saisissez votre **code PIN** (six chiffres). Vous pouvez appuyer sur **Afficher** pour vérifier ce que vous tapez.
4. Appuyez sur **Se connecter**.

Si le numéro ou le PIN est incorrect, un message vous le signale. Après plusieurs essais échoués, l'accès est temporairement bloqué : attendez quelques minutes avant de réessayer.

### Si vous oubliez votre PIN : les codes de récupération

Lors de votre inscription, MyCashBill vous remet **8 codes de récupération**. Chaque code ne sert qu'une fois.

> **Très important :** ces codes sont votre seule façon de retrouver l'accès sans l'aide du support. Gardez-les **sur papier**, dans un endroit sûr. Ne les envoyez à personne.

Pour récupérer votre compte :

1. Sur la page de connexion, appuyez sur **PIN oublié ?**.
2. Saisissez votre **numéro de téléphone**.
3. Saisissez **un** de vos codes de récupération.
4. Choisissez votre **nouveau PIN**, puis appuyez sur **Récupérer mon compte**.

Une fois le code utilisé, il ne fonctionne plus. Pensez à en noter un nouveau si vous en avez besoin.

## 4. Découvrir l'écran d'accueil et le menu

### L'écran d'accueil (Tableau de bord)

Après votre connexion, vous arrivez sur le **tableau de bord**. Vous y voyez :

- vos **statistiques** du moment (documents, clients, programmations…) ;
- vos **actions rapides** pour créer un document ;
- vos **documents récents** ;
- les **bandeaux d'information** : il vous indique par exemple combien de jours d'essai Pro il vous reste, ou les nouveautés.

En haut de l'écran, vous voyez aussi votre **quota** (une petite pastille avec le nombre de documents déjà utilisés ce mois-ci). Appuyez dessus pour voir le détail.

### Le menu sur téléphone (barre du bas)

Cinq boutons vous permettent de naviguer :

| Bouton | À quoi il sert |
|---|---|
| **Accueil** | Revenir au tableau de bord. |
| **Historique** | Voir tous vos documents. |
| **Nouveau** (bouton vert au centre) | Créer un nouveau document. C'est le bouton que vous utiliserez le plus. |
| **Clients** | Gérer votre liste de clients. |
| **Profil** | Vos paramètres, vos informations d'entreprise et votre compte. |

### Le menu sur ordinateur (colonne de gauche)

Sur ordinateur, les mêmes rubriques sont dans une colonne à gauche : **Nouveau**, **Historique**, **Clients**, **Récurrents** et **Profil**. Une rubrique **Console Admin** n'apparaît que pour les comptes d'administration.

### Changer de langue

En haut de l'écran, appuyez sur **FR** ou **EN** pour passer en français ou en anglais. Votre choix est mémorisé.

## 5. Préparer les informations de votre entreprise

**C'est l'étape la plus importante avant votre premier document.** Les informations de votre entreprise apparaissent sur chaque document que vous émettez.

Pour les renseigner : appuyez sur **Profil**, puis sur **Informations légales** (ou **Paramètres**, puis **Entreprise**).

### Les champs à remplir

| Champ | Exemple | À quoi il sert |
|---|---|---|
| **Raison sociale** | « Boutique Akwa SARL » | Le nom officiel de votre entreprise. |
| **Forme juridique** | « SARL », « Entreprise individuelle » | Le statut de votre entreprise. |
| **NIU / NIF** | « P0123456789 » | Votre numéro d'identification fiscale. |
| **RCCM** | « RC/DLA/2024/B/1234 » | Votre numéro au registre du commerce. |
| **Adresse** | « Douala, Akwa, rue 12 » | L'adresse de votre entreprise. |

> **Pourquoi certains documents vous demandent des informations de plus ?** Chaque type de document a ses propres exigences. Une facture demande plus d'informations qu'un ticket de caisse. Si une information manque, MyCashBill vous affiche un encadré **« Profil entreprise incomplet »** avec le bouton **Compléter mon profil**. Vous n'avez pas besoin de deviner : il vous mène directement au bon champ.

### Votre logo, votre signature et votre cachet

Vous pouvez ajouter trois images : un **logo**, une **signature** et un **cachet**.

- Formats acceptés : **PNG** ou **JPEG**.
- Taille maximale : **200 Ko** pour le logo, **50 Ko** pour la signature et pour le cachet.
- Astuce : pour une signature, écrivez votre nom sur une feuille blanche, photographiez-la, puis recadrez la photo sur votre signature.

> **Attention :** le logo, la signature et le cachet sont réservés à l'offre **Pro** (voir chapitre 12). Vous pouvez les préparer dès maintenant, ils apparaîtront sur vos documents quand vous passerez Pro.

### Votre texte d'en-tête et de pied de page

Vous pouvez aussi écrire un **texte d'en-tête** et un **texte de pied de page** (par exemple, votre slogan ou vos coordonnées bancaires). Ils apparaissent en haut et en bas de vos documents.

Appuyez sur **Enregistrer** une fois vos informations saisies. Un message de confirmation apparaît.

## 6. Ajouter votre premier client

Vos clients sont enregistrés dans la rubrique **Clients**. Vous n'êtes pas obligé de les ajouter à l'avance : vous pouvez aussi les créer directement pendant la création d'un document (voir chapitre 7).

Mais l'ajout à l'avance vous fait gagner du temps à chaque document.

### Comment ajouter un client

1. Appuyez sur **Clients**, puis sur **Nouveau client**.
2. Remplissez les informations :

| Champ | Obligatoire ? | Conseil |
|---|---|---|
| **Nom** | Oui | Le nom de la personne ou de l'entreprise. |
| **Téléphone** | Non | Indispensable si vous voulez envoyer par WhatsApp. |
| **Email** | Non | Indispensable si vous voulez envoyer par email. |
| **Adresse** | Non | Utile pour les bons de livraison. |
| **Note** | Non | Par exemple : « Paie toujours à la livraison ». |
| **NIU / NIF du client** | Non | Pour les clients entreprises (B2B). |
| **Pays du client** | Non | Laissé sur le pays par défaut si vous ne changez rien. |

3. Appuyez sur **Enregistrer**.

### Modifier ou supprimer un client

Ouvrez la fiche du client en appuyant sur **Voir**, à droite de son nom. Vous pouvez la modifier. Pour supprimer un client, utilisez le bouton **Supprimer**.

> **Bon à savoir :** supprimer un client **ne supprime pas** les documents qui lui sont associés. Ils restent dans votre historique.

> **Limite gratuite :** l'offre gratuite permet d'enregistrer **2 clients**. Au-delà, il faut passer Pro (chapitre 12). Vos documents existants ne sont pas touchés.

## 7. Créer votre premier document

C'est le cœur de MyCashBill. Suivez les étapes dans l'ordre.

### Étape 1 : appuyer sur « Nouveau »

Appuyez sur le bouton vert **Nouveau** (en bas au centre sur téléphone, ou dans la colonne de gauche sur ordinateur).

### Étape 2 : choisir le type de document

MyCashBill vous propose **sept types de documents**. Choisissez celui qui correspond à votre situation :

| Type | À utiliser quand… |
|---|---|
| **TICKET** (ticket de caisse) | Vous faites une vente au comptant, sans TVA. Reçu simplifié. |
| **REÇU** | Votre client vous a payé. Le reçu prouve le paiement et solde la dette. |
| **DEVIS** | Vous proposez un prix à votre client. Le devis devient un contrat quand le client l'accepte. |
| **FACTURE PROFORMA** | Vous voulez un document de pré-engagement. Il n'a pas de valeur fiscale. |
| **BON DE COMMANDE** | Votre client veut acheter. Ce document sert de base à votre facturation. |
| **BORDEREAU DE LIVRAISON** | Vous livrez des marchandises. Le destinataire le signe comme preuve de livraison. |
| **FACTURE** | Vous facturez une vente ou une prestation. C'est le document fiscal obligatoire pour la TVA et la comptabilité. |

> **Attention :** une fois le **brouillon** créé, le type ne peut plus être changé. Choisissez donc bien dès le départ. En cas d'erreur, supprimez le brouillon et recommencez.

### Étape 3 : choisir le client

Dans le champ **Client**, deux options :

- **Client existant** : choisissez dans la liste.
- **Nouveau client** : saisissez son nom, puis ses coordonnées si vous les avez. Ce client sera enregistré automatiquement.

### Étape 4 : remplir les articles ou les prestations

C'est la partie qui contient le détail de votre vente. Pour chaque ligne :

1. Écrivez la **désignation** (par exemple « Chemise en lin » ou « Développement site web »).
2. Indiquez la **quantité**.
3. Indiquez le **prix unitaire**. Le total de la ligne se calcule tout seul.

Appuyez sur **Ajouter une ligne** pour en ajouter d'autres. Appuyez sur **Retirer** pour en supprimer une.

> **Astuce :** sous le champ de désignation, des **suggestions rapides** apparaissent. Un simple clic les ajoute à votre document.

### Étape 5 : ajuster les montants

Selon le type de document, vous pouvez indiquer :

- la **TVA** en pourcentage ;
- un **acompte** en pourcentage, si le client paie une partie à l'avance ;
- des **frais de livraison** ;
- une **remise** ou des **notes**.

Le **sous-total**, la **TVA**, l'**acompte** et le **total** se mettent à jour automatiquement au fur et à mesure.

### Étape 6 : renseigner les informations complémentaires

Selon le type de document, MyCashBill vous demande d'autres informations, par exemple :

- **Durée de validité** (pour un devis) ;
- **Échéance de paiement** (pour une facture) ;
- **Mode de règlement** : espèces, Mobile Money, virement bancaire ou chèque ;
- **Référence de la transaction**, par exemple le numéro de votre paiement Mobile Money ;
- **Date et adresse de livraison** (pour un bordereau).

> **Astuce :** les **motifs récents** s'affichent juste en dessous. Cliquez sur l'un d'eux pour le réutiliser sans le retaper.

### Étape 7 : choisir le format

Deux formats sont proposés :

- **Ticket 80 mm** : le format des imprimantes de caisse. Idéal pour les ventes au comptant.
- **A4** : le format classique des feuilles de bureau.

### Étape 8 : générer le document

Relisez tout, puis appuyez sur **Générer le document**.

MyCashBill crée le document, lui attribue automatiquement un **numéro** (par exemple `MCB-000012`) et vous emmène sur sa page d'aperçu.

### Votre brouillon est sauvegardé automatiquement

Pendant que vous remplissez le formulaire, MyCashBill **sauvegarde votre brouillon** sur votre appareil. Si vous fermez l'application, un message vous propose de **reprendre** le brouillon la prochaine fois. Vous pouvez aussi choisir de l'**ignorer**.

> **Bon à savoir :** le brouillon est gardé même sans connexion internet. Vous pouvez donc commencer un document dans un endroit sans réseau.

## 8. Prévisualiser et envoyer un document

Après avoir généré un document, vous arrivez sur son **aperçu**. C'est là que vous décidez quoi en faire.

### Vérifier l'aperçu

Vous voyez le document tel que votre client le recevra. Vérifiez le nom, les montants et les coordonnées.

Si vous voyez une erreur, appuyez sur **Modifier**. Vous pouvez corriger un document **une seule fois** dans l'offre gratuite.

### Envoyer par WhatsApp

1. Appuyez sur **Envoyer**.
2. Dans le champ **Téléphone WhatsApp du client**, saisissez son numéro. Vous pouvez aussi laisser ce champ vide et choisir le contact directement dans WhatsApp.
3. Un **message type** est proposé. Vous pouvez le modifier librement. Il est mémorisé pour la prochaine fois. Le bouton **Réinitialiser au modèle** rétablit le message d'origine.
4. **Joindre le fichier XML (optionnel) :** cochez la case **« Joindre aussi le fichier XML (facturation électronique) »** si vous souhaitez transmettre à votre client ou son comptable le format numérique universel.
5. Appuyez sur **Envoyer sur WhatsApp**. WhatsApp s'ouvre avec le message et les pièces prêtes à partir.

> **Limite gratuite :** l'offre gratuite permet **5 envois WhatsApp par mois**.

### Envoyer par email

L'envoi par email est réservé à l'offre **Pro**. Saisissez l'adresse email de votre client, puis appuyez sur **Envoyer par email**.

### Télécharger le PDF

Appuyez sur **Télécharger le PDF** pour enregistrer le document sur votre téléphone ou votre ordinateur. C'est utile pour l'imprimer, ou pour l'envoyer par un autre moyen.

### Télécharger le fichier XML (facture électronique)

À côté du bouton PDF, vous pouvez appuyer sur **Télécharger le XML**. Ce fichier au format standard international **UBL 2.1** contient toutes les données de votre facture de façon informatique. Votre comptable ou votre client peut ainsi l'importer directement dans son logiciel comptable sans ressaisie.

### Partager autrement

Le bouton **Partager autrement** ouvre le menu de partage de votre téléphone (Bluetooth, AirDrop, autres applications…). Cette option est réservée à l'offre Pro.

### Imprimer

Appuyez sur **Télécharger le PDF**, puis imprimez le fichier depuis votre application de lecture PDF.

### Savoir si le document a bien été envoyé

Un document envoyé porte la mention **Envoyé** dans votre historique. Un document qui n'a pas encore été envoyé est marqué **Brouillon**.

## 9. Retrouver vos documents dans l'historique

Appuyez sur **Historique** pour voir tous vos documents, du plus récent au plus ancien.

### Chercher et ouvrir un document

Chaque ligne affiche le numéro, le client, le montant et le statut. Appuyez sur **Voir** pour ouvrir le document.

### Supprimer un document

Vous pouvez supprimer un document **tant qu'il n'a pas été envoyé**. Appuyez sur la corbeille ou sur **Supprimer**, puis confirmez.

> **Attention :** la suppression est **définitive**. Un document envoyé ne peut plus être supprimé : il reste dans votre historique, pour votre sécurité et la leur.

### Télécharger vos documents en une seule fois

Appuyez sur **Télécharger l'historique**, puis choisissez la période :

- Aujourd'hui ;
- 7 derniers jours ;
- 30 derniers jours ;
- 12 derniers mois ;
- Personnalisé.

Appuyez sur **Tout exporter (ZIP)** : vous recevez un fichier ZIP contenant vos PDF. C'est la bonne façon de conserver une copie de vos documents.

> **Limite gratuite :** l'offre gratuite affiche les documents des **7 derniers jours**. Les plus anciens sont masqués. Ils ne sont pas supprimés, et l'offre Pro vous les rend visibles.

## 10. Programmer un document ou une facturation récurrente

Cette fonction est réservée à l'offre **Pro**. Elle est très utile pour les loyers, les abonnements ou les contrats qui reviennent chaque mois.

### Programmer un document

Depuis l'aperçu d'un document, appuyez sur **Programmer**. Choisissez :

- la **fréquence** : quotidienne, hebdomadaire ou mensuelle ;
- une **étiquette** pour vous y retrouver, par exemple « Loyer boutique » ;
- si vous voulez que MyCashBill **envoie automatiquement** la copie par email au client.

Appuyez sur **Enregistrer la programmation**.

### Retrouver et gérer vos programmations

Ouvrez la rubrique **Récurrents** (sur ordinateur, dans la colonne de gauche). Pour chaque programmation, vous voyez :

- son état : **Active** ou **En pause** ;
- la date de la **prochaine** création ;
- la date de la **dernière** création et le nombre de documents générés.

Vous pouvez **mettre en pause**, **reprendre** ou **supprimer** une programmation à tout moment.

## 11. Envoyer un même document à plusieurs clients

L'**envoi en masse** permet d'émettre le même document pour plusieurs clients en une seule fois. Par exemple : une annonce de prix, une facture commune, un avis de paiement.

Cette fonction est réservée à l'offre **Pro**.

1. Depuis l'aperçu du document, appuyez sur **Envoi en masse**.
2. Sélectionnez vos clients. Le bouton **Tout** sélectionne les premiers de la liste, **Aucun** les désélectionne tous.
3. Choisissez le canal : **email** ou **WhatsApp**.
4. Appuyez sur **Envoyer à X destinataire(s)**.

Un écran de résultat vous indique ce qui a réussi et ce qui a échoué. Pour WhatsApp, vous pouvez ouvrir chaque conversation une par une.

> **Bon à savoir :** un client sans numéro de téléphone (pour WhatsApp) ou sans adresse email (pour l'email) ne peut pas être sélectionné. Complétez sa fiche dans **Clients** avant l'envoi.

## 13. Passer en Pro

1. Ouvrez la rubrique **Passer Pro** (depuis le menu, ou depuis le bandeau qui vous le propose).
2. Choisissez votre **formule** (1, 3 ou 12 mois).
3. Choisissez votre **devise** si l'option est proposée.
4. Choisissez votre mode de paiement :
   - **Mobile Money**, si votre pays le permet ;
   - **Carte bancaire** (Visa, Mastercard), si elle est disponible.
5. Suivez les instructions de paiement.

Une fois le paiement confirmé, votre compte passe Pro. Une page de remerciement vous le confirme, et votre **statut** affiche la date d'expiration (« Expire le … »).

> **Bon à savoir :** votre abonnement ne se renouvelle **pas** automatiquement. Quand il arrive à son terme, vous repassez en gratuit, mais vos documents restent accessibles. Pensez à renouveler avant la date d'expiration.

> **Un doute sur le paiement ?** Ouvrez la rubrique **Mes factures d'abonnement** (chapitre 18) pour retrouver le justificatif.

### Les extensions payantes

Certaines fonctions complémentaires sont proposées séparément sur la page **Passer Pro** :

- **Appareil supplémentaire** ;
- **WhatsApp personnalisé** (utiliser votre propre numéro WhatsApp pour les envois) ;
- **Sans marque** (retirer complètement le nom MyCashBill de vos documents).

Chaque extension est indiquée avec son prix mensuel. Appuyez sur **Explication** pour lire ce qu'elle fait exactement avant de vous décider.

## 14. Parrainer un ami

Le parrainage vous permet de gagner des jours Pro gratuits.

1. Ouvrez la rubrique **Parrainage**.
2. Copiez **votre lien** (bouton **Copier le lien**) ou partagez-le directement sur **WhatsApp**.
3. Quand votre ami crée son compte avec votre code et l'active, vous gagnez **7 jours Pro**.

Vous pouvez gagner jusqu'à **30 jours Pro** cumulés par ce moyen. La page affiche le nombre de filleuls inscrits, le nombre de filleuls activés et les jours Pro que vous avez gagnés.

> **Astuce :** votre ami, lui aussi, peut saisir votre code à l'inscription pour gagner des jours.

## 15. Gérer vos appareils

Pour votre sécurité, votre compte peut être utilisé sur un nombre limité d'appareils :

- **1 appareil** en offre gratuite ;
- **2 appareils** en offre Pro.

Ouvrez la rubrique **Mes appareils** (dans **Profil**) pour voir la liste.

### Connecter un nouvel appareil

Quand vous vous connectez depuis un appareil nouveau, MyCashBill vous demande une **approbation**. Il faut alors confirmer depuis un appareil déjà connecté :

1. Sur l'appareil déjà connecté, ouvrez **Mes appareils**, puis **Approuver un nouvel appareil**.
2. Un **code à six chiffres** apparaît. Il n'est valable que **5 minutes**.
3. Saisissez ce code sur le nouvel appareil pour finaliser la connexion.

Après trois mauvaises saisies, le code n'est plus valable : recommencez la demande.

### Révoquer un appareil

Si vous avez perdu un téléphone ou si vous ne reconnaissez pas un appareil, appuyez sur **Révoquer** à côté de cet appareil. Il devra se reconnecter.

> **Bon réflexe :** si vous revendez ou prêtez votre téléphone, révoquez l'appareil avant.

## 16. Installer MyCashBill sur votre téléphone ou votre ordinateur

Vous pouvez installer MyCashBill comme une application, sans passer par un magasin d'applications. Vous retrouvez alors une icône sur votre écran d'accueil.

- **Sur Android ou un ordinateur :** un bouton **Installer** apparaît dans l'en-tête ou dans le menu. Appuyez dessus et confirmez.
- **Sur iPhone :** appuyez sur le bouton **Partager** du navigateur (⎋), puis sur **Sur l'écran d'accueil**.

### Travailler sans connexion internet

Une fois installée, l'application continue de fonctionner sans réseau pour **préparer vos documents**. Vos brouillons sont sauvegardés localement. Un bandeau vous indique quand vous êtes hors ligne, puis **« Connexion rétablie »** quand le réseau revient.

> **Important :** l'envoi (WhatsApp, email) a besoin d'une connexion internet. Préparez votre document hors ligne, puis envoyez-le dès que le réseau revient.

Un bandeau vous informe aussi quand une **mise à jour** est disponible. Rechargez la page pour en profiter.

## 17. Vérifier l'authenticité d'un document

Chaque document porte un **code QR**. Une personne qui reçoit votre document peut le scanner avec son téléphone pour vérifier qu'il a bien été émis par MyCashBill.

La page de vérification affiche :

- le **type** et le **numéro** du document ;
- la **date d'émission** ;
- l'**entreprise émettrice**.

Si le document ne correspond à aucun enregistrement, la page le signale. Un document signalé comme frauduleux doit être considéré avec prudence.

## 19. Questions fréquentes

**Mon document n'a pas de numéro, pourquoi ?**
Le numéro est attribué au moment où vous appuyez sur **Générer le document**. Un brouillon n'en a pas encore.

**Puis-je modifier un document déjà envoyé ?**
Vous pouvez le corriger tant qu'il n'a pas été envoyé. Une fois envoyé, il est préférable d'émettre un nouveau document : c'est plus clair pour votre client.

**J'ai perdu mon téléphone. Que faire ?**
Connectez-vous depuis un nouvel appareil. Si l'approbation est demandée, utilisez un appareil encore connecté, ou vos codes de récupération (chapitre 3).

**Pourquoi le bouton « Ajouter un logo » ne marche pas ?**
Vérifiez la taille et le format de votre image : PNG ou JPEG, 200 Ko maximum pour le logo. Le logo est réservé à l'offre Pro.

**Pourquoi je ne peux pas envoyer par email ?**
L'envoi par email est réservé à l'offre Pro. Vérifiez aussi que votre client a une adresse email enregistrée.

**Mon client ne reçoit pas le message WhatsApp.**
Vérifiez le numéro, en particulier l'indicatif du pays. Le message s'ouvre dans WhatsApp : vous devez appuyer sur **Envoyer** dans WhatsApp pour finaliser.

**Le bandeau « Profil entreprise incomplet » ne disparaît pas.**
Un champ obligatoire manque encore. Appuyez sur **Compléter mon profil** : il vous indique lequel.

**Je ne retrouve plus mon brouillon.**
Les brouillons sont sauvegardés sur l'appareil où vous les avez créés. Vérifiez que vous êtes sur le même appareil et le même navigateur.

**Je n'arrive plus à me connecter.**
Vérifiez votre numéro et votre PIN. Après plusieurs essais échoués, attendez quelques minutes. Si le problème persiste, utilisez **PIN oublié ?**.

## 20. Lexique

| **Filleul** | Personne que vous avez parrainée. |

| **Code PIN** | Code à six chiffres qui protège votre accès. |
| **Code de récupération** | Code à usage unique pour retrouver l'accès à votre compte. |
